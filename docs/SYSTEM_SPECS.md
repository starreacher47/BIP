# Описание системы

## Назначение
Система снижает вероятность компрометации токенов и захвата сессий посредством пассивного анализа HTTP-трафика, набора настраиваемых правил, корреляции клиентов и контролируемых лабораторных тестов.

## Компоненты
Flask обслуживает UI и REST API; SQLite хранит пользователей, сессии, находки, события токенов и журналы. mitmproxy передаёт обезличенные захваты в API. WebSocket сообщает прогресс загрузки. MinIO хранит объекты. Keycloak предоставляет локальный OAuth/OIDC. Nginx завершает TLS. Prometheus собирает метрики приложения и Node Exporter, Grafana визуализирует CPU, RAM, RPS и 429.

## Потоки данных
Запрос получает UUIDv7, проверяется по SOP/CORS, CSP/CSRF и rate limit. Аутентифицированный захват нормализуется, токены хешируются SHA-256, сохраняются только превью и метаданные. Правила создают findings с категорией, уровнем риска и рекомендацией.

## Роли
`user` работает со своими сессиями и файлами; `admin` анализирует находки и создаёт API keys; `superuser` управляет ролями, блокировкой пользователей, всеми сессиями и внешними токенами.
