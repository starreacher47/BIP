# Руководство пользователя

1. Зарегистрируйтесь, выбрав подтверждение email, телефона или токен приглашения.
2. Войдите и включите TOTP 2FA в разделе «Безопасность»; добавьте показанный секрет в приложение-аутентификатор.
3. В кабинете просматривайте и отзывайте активные сессии.
4. Для больших файлов запросите upload ID через API, передавайте части и подписывайтесь по Socket.IO на комнату с ID загрузки.
5. Владелец файла может создать ссылку на 24 часа. Прямой URL без действующей сессии или share token возвращает 403/404.
6. Администратор включает/выключает правила аудита, управляет пользователями, API keys и формирует PDF.
